# 個人作品集網站 (Personal Portfolio Website)

一個簡約、溫潤風格的個人作品集網站，用於記錄大學期間的學習歷程、技術累積與專案作品。

## 🎨 設計特色

- **莫蘭迪大地色調**：採用溫潤米色與奶茶色系（Morandi Style），提供舒適無壓力的閱讀體驗。
- **純粹輕量化**：使用原生 HTML5 與 CSS3 編寫，無須依賴額外框架或套件，載入速度極快。
- **CSS 變數支援**：全站顏色透過 `:root` 變數管理，方便快速調整主題配色。
- **響應式版面**：支援 Mobile 與 Desktop 跨裝置瀏覽體驗（Grid & Flexbox）。
